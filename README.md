# ST3189-Coursework
A comparative machine learning study applying unsupervised clustering, regression, and classification across three real-world datasets in Python. Key results: K-Means segmentation (ARI = 0.74), Random Forest housing prediction (R² = 0.84), and Logistic Regression heart disease diagnosis (ROC-AUC = 0.870).
The project will consist of completing the following three tasks implemented on threee real-world datasets.

1. Unsupervised Learning: where the problem consists of identifying homogeneous population groups or dimension reduction techniques, which can then be used in the context of the empirical application

2. Regression: where the problem consists of continuous target variable(s).

3. Classification: where problem consists of categorical target variable(s).
